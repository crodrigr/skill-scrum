# 🟢 Básico 02 — Valores, principios y ventajas del enfoque ágil

> 🟢 **Nivel:** Básico · 🎓 **Resultados de aprendizaje:** RA-2, RA-3

## 🧱 Estado inicial

Tenés estas cinco situaciones de equipos de software y seis frases sobre las metodologías
ágiles.

**Situaciones**

- **S1.** El cliente de una tienda en línea pide cambiar el medio de pago a mitad del proyecto
  y el equipo lo incorpora en el siguiente ciclo.
- **S2.** Cada dos semanas el equipo entrega una versión que ya funciona para que el cliente
  la pruebe.
- **S3.** Los desarrolladores se sientan todos los días con la persona del negocio para
  resolver dudas, en lugar de esperar un documento firmado.
- **S4.** Ante un problema, el equipo lo resuelve con una conversación rápida, sin esperar un
  procedimiento formal de tickets.
- **S5.** El equipo se compromete a no trabajar de noche ni los fines de semana, para poder
  sostener su ritmo durante todo el proyecto.

**Los cuatro valores del manifiesto**

1. Individuos e interacciones sobre procesos y herramientas.
2. Software funcionando sobre documentación extensiva.
3. Colaboración con el cliente sobre negociación contractual.
4. Respuesta ante el cambio sobre seguir un plan.

**Los cinco temas de principios**: Entrega de valor, Cambio y cliente, Personas y equipo,
Calidad y simplicidad, Mejora continua.

**Frases sobre las ágiles**

- **a.** Permite entregar valor al cliente desde las primeras semanas.
- **b.** Es difícil prever con exactitud el costo y la fecha del alcance completo.
- **c.** Permite incorporar cambios sin un costo tan alto.
- **d.** Requiere que el cliente esté disponible con frecuencia.
- **e.** Da visibilidad del avance al final de cada ciclo.
- **f.** Exige mucha disciplina y madurez del equipo.

## 🛠️ Proceso esperado

1. Para cada situación (S1 a S5), indicar **un valor** (1 a 4) y **un tema de principios**
   que la explica, con una frase de justificación.
2. Para cada frase (a a f), indicar si es una **ventaja** o una **desventaja** de las
   metodologías ágiles.

## ✅ Resultado esperado

- ☑️ Cinco filas (S1 a S5), cada una con un valor, un tema y una justificación.
- ☑️ Seis frases clasificadas como ventaja o desventaja.
- ☑️ Todas las justificaciones aclaran que el valor de la derecha no se descarta.

## 🚧 Restricciones

- 🚫 Cada situación se asocia a un único valor y a un único tema.
- 🚫 No usar ninguna situación para decir que "ágil" significa "sin plan".
- 🚫 Cada justificación debe tener una sola frase.

## 🎓 Resultados de aprendizaje

- RA-2: Enunciar el manifiesto ágil, sus valores y sus principios.
- RA-3: Identificar las ventajas y desventajas de las metodologías ágiles.
