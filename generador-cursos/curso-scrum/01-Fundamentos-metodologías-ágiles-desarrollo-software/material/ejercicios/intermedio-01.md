# 🟡 Intermedio 01 — Clasificar proyectos: Cascada, Prototipado o Espiral

> 🟡 **Nivel:** Intermedio · 🎓 **Resultados de aprendizaje:** RA-4

## 🧱 Estado inicial

Tenés tres descripciones de proyectos.

- **P1.** Un sistema de nómina para una entidad pública. Los requisitos están completos y
  firmados desde el inicio. El trabajo avanza por fases consecutivas y cada fase termina con
  un documento aprobado antes de pasar a la siguiente.
- **P2.** Una aplicación de reservas cuyo cliente no sabe cómo quiere que se vea ni cómo se
  use. El equipo construye maquetas navegables para que las pruebe y ajusta antes de
  programar la versión final.
- **P3.** Un sistema de control para un dispositivo médico con riesgos técnicos muy altos. El
  trabajo avanza en vueltas y cada vuelta empieza evaluando los riesgos para decidir qué
  versión más completa se construye.

## 🛠️ Proceso esperado

1. Asignar a cada descripción **una** metodología tradicional: Cascada, Prototipado o
   Espiral.
2. Justificar la elección señalando **dos rasgos** de la descripción que la sustentan.
3. Indicar para cada proyecto **una limitación** de la metodología elegida.

## ✅ Resultado esperado

- ☑️ Una tabla con tres filas (P1 a P3), cada una con metodología, dos rasgos y una
  limitación.
- ☑️ Cada metodología se usa exactamente una vez.
- ☑️ Las limitaciones corresponden a la metodología elegida y no a otra.

## 🚧 Restricciones

- 🚫 Cada metodología se asigna a un solo proyecto.
- 🚫 Los rasgos deben citarse de la descripción, no inventarse.
- 🚫 No mencionar metodologías ágiles en la justificación.

## 🎓 Resultados de aprendizaje

- RA-4: Describir las metodologías tradicionales Cascada, Prototipado y Espiral.
