# 🟢 Básico 01 — Las cuatro etapas del flujo de un sprint

> 🟢 **Nivel:** Básico · 🎓 **Resultados de aprendizaje:** RA-1

## 🧱 Estado inicial

Un equipo que desarrolla la **aplicación para reservar canchas de pádel** quiere explicarle a una
persona nueva cómo se recorre un proyecto con Scrum. Tenés cuatro etapas desordenadas y cuatro cosas
que se obtienen.

**Etapas desordenadas**

- **a.** Ejecución con el tablero.
- **b.** Dividir las épicas en historias de usuario.
- **c.** Planificar el sprint y formar el Sprint Backlog.
- **d.** Definir el objetivo del producto y las épicas.

**Qué se obtiene (desordenado)**

- **1.** Un incremento utilizable.
- **2.** Épicas.
- **3.** Historias ordenadas, con criterio de aceptación.
- **4.** La lista del sprint.

## 🛠️ Proceso esperado

1. Ordenar las cuatro etapas (a a d) en la secuencia en que ocurren.
2. Relacionar cada etapa con lo que se obtiene en ella (1 a 4).
3. Indicar dos cosas que **no cambian** durante un sprint.

## ✅ Resultado esperado

- ☑️ La secuencia correcta de las cuatro etapas.
- ☑️ Cuatro parejas etapa–resultado, sin repetir ninguna.
- ☑️ Dos elementos que se mantienen fijos durante el sprint.

## 🚧 Restricciones

- 🚫 Cada resultado se usa una sola vez.
- 🚫 No agregar etapas nuevas.
- 🚫 Cada respuesta del punto 3 debe tener una sola frase.

## 🎓 Resultados de aprendizaje

- RA-1: Describir el flujo de trabajo de un sprint de principio a fin y ubicar en él las cuatro etapas.
